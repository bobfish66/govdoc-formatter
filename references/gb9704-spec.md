# 公文格式速查（GB/T 9704-2012 +《党政机关公文处理工作条例》）

## 一、版式（第 4、5、7 章）

| 项目 | 标准值 | 备注 |
|---|---|---|
| 用纸 | A4（210mm×297mm） | 双面印刷 |
| 版心 | 156mm×225mm | 天头 37mm、订口 28mm；下白边 35mm、右白边 26mm |
| 每面 | 22 行、每行 28 字 | 行距固定 28.99pt 方能达到 22 行 |
| 装订 | 左侧装订 | 骑马订或平订 |

## 二、版头（6 个要素，纪要格式除外）

1. 份号：6 位阿拉伯数字，顶格编排在版心左上角第一行（涉密公文必备）
2. 密级和保密期限：3 号黑体，顶格编排在版心左上角第二行，密级与期限之间用“★”隔开
3. 紧急程度：3 号黑体，顶格编排在版心左上角（特急/加急），如需同时标注份号、密级、紧急程度，按份号—密级—紧急程度自上而下排列
4. 发文机关标志：小标宋体字，红色，上边缘至版心上边缘 35mm
5. 发文字号：3 号仿宋，年份用六角括号〔〕，不编虚位（如〔2026〕5 号）
6. 签发人：“签发人”三字加全角冒号后标注姓名，3 号仿宋，“签发人”用 3 号仿宋、姓名用 3 号楷体

## 三、主体（8 个要素）

| 要素 | 规范 |
|---|---|
| 标题 | 2 号小标宋，居中，回行时词意完整、排列对称、长短适宜、间距恰当，一般不超过 3 行，不用标点 |
| 主送机关 | 3 号仿宋，标题下空一行，左侧顶格，回行顶格，最后一个机关名称后加全角冒号 |
| 正文 | 3 号仿宋，主送机关下一行，每段首行左空二字，回行顶格 |
| 层次序数 | 一级“一、”黑体；二级“（一）”楷体；三级“1.”仿宋；四级“（1）”仿宋 |
| 附件说明 | 正文下空一行，左空二字编排“附件：”＋名称；多个附件用阿拉伯数字标序号（如“附件：1.×××”），名称后不加标点 |
| 发文机关署名 | 正文（或附件说明）下空一行，居右空二字 |
| 成文日期 | 阿拉伯数字，年月日标全，年份标全称，月日不编虚位（1 不编为 01），居右空四字 |
| 印章 | 上距正文（或署名）一行之内，端正、居中下压成文日期，首字上距正文一行之内 |
| 附注 | 成文日期下一行，左空二字，加圆括号（如“（此件公开发布）”） |

## 四、版记

- 抄送机关：在印发机关和印发日期之上一行，左空一字编排“抄送：”，回行时与冒号后的首字对齐，最后一个机关名称后加句号
- 印发机关和印发日期：版记中最后一行，印发机关左空一字，印发日期右空一字，阿拉伯数字标全年月日，后加“印发”二字
- 版记中的分隔线：首条与末条用粗线（0.35mm），中间用细线（0.25mm）

## 五、页码（第 7.5 条）

- 4 号半角宋体阿拉伯数字，编排在版心下边缘之下，数字左右各放一条一字线
- 一字线上距版心下边缘 7mm
- 单页码居右空一字，双页码居左空一字
- 空白页不标页码；公文的附件与正文一起装订时页码连续编排

## 六、附件（第 7.4 条）

- 另面编排，与正文一起装订，“附件”二字及附件顺序号用 3 号黑体顶格编排在版心左上角第一行
- 附件标题居中编排在版心第三行
- 附件顺序号和标题应与附件说明一致

## 七、《党政机关公文处理工作条例》要点

- 第九条：公文格式要素分版头、主体、版记三部分，共 18 项
- 第十五种法定文种：决议、决定、命令（令）、公报、公告、通告、意见、通知、通报、报告、请示、批复、议案、函、纪要
- 行文规则：请示应当一文一事，不得多头主送；报告不得夹带请示事项；向下级机关行文必要时抄送上级机关

## 八、字体依赖提示

- 标准字体：方正小标宋简体（标题）、仿宋_GB2312（正文）、楷体_GB2312、黑体
- 若本机缺失上述字体，Word 预览会替代显示，但文档内保留标准字体名，在安装字体的电脑上打开即为标准效果
